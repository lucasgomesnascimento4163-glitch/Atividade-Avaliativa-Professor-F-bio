# Portfólio Simples — Lucas

Site pessoal feito com HTML, CSS e JavaScript, organizado em cards e responsivo para celular.

## Arquivos
- `index.html` — conteúdo (troque os textos de exemplo pelos seus)
- `style.css` — estilos e responsividade
- `script.js` — menu do celular e ano do rodapé

## Publicar no GitHub Pages
```bash
git init
git add .
git commit -m "Portfólio simples"
git branch -M main
git remote add origin https://github.com/SEU-USUARIO/SEU-REPOSITORIO.git
git push -u origin main
```
No GitHub: Settings → Pages → Deploy from a branch → main / (root).
